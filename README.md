# Factory-to-Customer Shipping Route Efficiency Analysis

## 📌 Project Overview

This project analyzes factory-to-customer shipping routes for Nassau Candy Distributor to identify shipping efficiency, delivery delays, geographic bottlenecks, and route performance.

The project includes data cleaning, exploratory analysis, route-level KPI calculation, and an interactive Streamlit dashboard.

## 🎯 Objectives

- Validate order and shipment dates
- Calculate shipping lead time
- Analyze factory-to-customer routes
- Compare shipping modes
- Identify geographic bottlenecks
- Analyze high-volume and inefficient routes
- Calculate route efficiency KPIs
- Provide an interactive dashboard for route analysis

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Streamlit
- Git & GitHub

## 📊 Key Analysis

The project analyzes:

- Shipping Lead Time
- Average Lead Time
- Lead-Time Variability
- Route Volume
- Delay Frequency
- Route Efficiency Score
- Factory-to-Region routes
- Factory-to-State routes
- Ship Mode performance
- Geographic bottlenecks

## 📈 Dashboard Features

The Streamlit dashboard provides:

- Route Efficiency Overview
- Geographic Shipping Analysis
- Ship Mode Comparison
- Regional Bottleneck Analysis
- Route Drill-Down
- Shipment Record Details
- Interactive filters and visualizations
